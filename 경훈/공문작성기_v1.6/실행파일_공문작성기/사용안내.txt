공문 작성기 사용안내
====================

서식을 고르고 받는 분 이름과 날짜만 넣으면, 홈넷 전자결재 → 문서작성 → 표준기안문에
제목·수신자·본문을 자동으로 넣어 줍니다. 결재올림(상신)은 직접 누릅니다.

■ v1.6 바뀐 점
  - [🔗 관련 문서번호] : 문서 제목 대신 문서번호로 문서링크를 넣습니다(제목이 같은 문서가 많아서).
      예) 광주우산3관리소-1234  또는 번호만 1234   (여러 개는 쉼표)
      · 홈넷 [문서링크] 창에서 '등록번호'로 찾아 번호가 꼭 맞는 문서만 고릅니다.
      · 올해 대장에 없으면 지난 3년 대장에서 찾습니다. 문서번호는 해마다 1부터 다시 매기므로
        지난해 문서는 날짜를 붙여 적으면 그 해 대장에서만 찾습니다.  예) 광주우산3관리소-12(2025. 1. 2.)
      · 본문에는 '광주우산3관리소-1234(2026.11.02.)'처럼 누르면 열리는 링크로 들어갑니다.
      · 번호가 아닌 말을 적으면 예전처럼 제목으로 찾습니다. 보안 문서는 [추가]가 안 되어 직접 넣어야 합니다.
  - [대장 문서 받기] 중단 : 받는 동안 작은 창이 뜹니다. [■ 그만 받기]를 누르면 지금 문서까지만 받고 멈추고,
      받은 문서는 PDF·서식으로 정리합니다(완료 창에 '중간에 그만 받았습니다' 표시).
  - 기본정보 : 관리소·단지명·담당자·홈넷 계정을 한 번 저장하면 서식을 고를 때마다 묻지 않습니다.
      고칠 때는 [파일 → 기본정보 고치기]. ('계정 기억하기'를 끄면 다음 실행 때 계정을 다시 묻습니다)
  - [✔ 올바른 문서 만들기] (공문 작성 화면 '2. 확인하기' 단추)
      공문서 작성 규칙에 맞지 않는 곳을 찾아 자동으로 고치고, 고친 곳을 보여 줍니다.
      · 날짜 2026.10.8 → 2026. 10. 8.   요일 2026. 10. 8. (목) → 2026. 10. 8.(목)
      · 시간 오후 2시 30분 → 14:30
      · 금액 1250000원 → 1,250,000원,  금 1,250,000원 → 금1,250,000원(금일백이십오만원)
      · 항목 번호 1. 3. → 1. 2.,  가. 다. → 가. 나.,  '3.점검' → '3. 점검'
      · 붙임 '붙임: 명단 1부' → '붙임  명단 1부.',  끝 표시가 없으면 '  끝.'을 붙임
      · 행정용어 익일 → 다음 날, 금일 → 오늘, 상기 → 위, 하기와 같이 → 아래와 같이, 에 의거 → 에 따라
      한 번 누르면 그 뒤로 이름·날짜를 바꿔 넣어도 같은 규칙으로 맞춰 줍니다(다른 서식을 고르면 꺼짐).
      서식 본문도 고쳐 두니 다음에도 쓰려면 [고친 내용을 서식에 저장]을 누르세요.
      [✏ 본문 직접 고치기] 중에 누르면 그 글을 고칩니다.

■ v1.5 바뀐 점 (KODAS 최신판 + 대장 문서 받기 + 관련 문서 링크)
  - 기준 : AI 2팀 KODAS 최신판(11-05 설치본 — 문단 내어쓰기·붙임 탭, 차수 Enter로 결과 통보 찾기,
           빨간 * 꼭 넣을 칸, 수신자 엑셀이면 이름·동호 칸 숨김)에 아래 기능을 더했습니다.
  - [대장 문서 받기] (처음 화면 바로가기, 또는 [파일 → 홈넷 대장 문서 받기])
      전자결재 → 대장관리 → 기록물등록대장을 자동으로 열고(제목 검색어를 넣으면 검색 결과부터)
      맨 위 문서부터 [다음]으로 넘기며 정한 개수만큼 받습니다. 받을 것을 고릅니다.
      · 문서를 PDF 파일로 받기 : 문서마다 PDF를 만듭니다. 이름·동호수·연락처·주민번호는 000으로 가립니다.
            예) 105동 814호 홍길동 귀하 → 000동 000호 000 귀하,  010-1234-5678 → 000-0000-0000
            관리소 대표번호(기본정보의 전화번호)는 가리지 않습니다.
      · 첨부파일도 받기 : 문서의 첨부파일을 받습니다. PDF 첨부도 같은 방법으로 000으로 가리고,
            가리기 전 원본 PDF는 남기지 않습니다. 한글·엑셀·그림 파일은 가릴 수 없어 그대로 두고
            완료 창에 목록을 보여 줍니다. 스캔(그림)만 있는 PDF와 암호가 걸린 PDF도 가리지 못해
            파일 이름 끝에 '(스캔본·가리지 못함)'·'(암호·가리지 못함)'을 붙여 둡니다. 직접 확인해 주세요.
      · 서식으로 넣기 : 받은 문서를 서식으로 바꿔 고른 분야의 '기타 공문 → 수집한 서식' 묶음에 넣습니다.
            받는 분 이름·동호수·연락처는 공문 쓸 때 넣는 칸({이름}·{주소}·{입력:연락처})이 되고,
            그 밖의 사람 이름은 000, 날짜·금액·문서번호는 빈칸·0000으로 바뀝니다.
      · 꼭 가릴 글자 : 자동으로 못 찾는 이름·동호수·연락처를 적으면(쉼표로 여러 개) PDF에서 함께 가립니다.
      · 받는 곳 : 프로그램 폴더의 '수집\날짜_시각' ([파일 → 받은 대장 문서 폴더 열기])
            PDF\{제목}.pdf · 첨부\{제목}\… · index.txt(목록)
            {제목}.txt·.html은 서식을 만들 때 쓰는 원문이라 가리지 않은 그대로입니다(밖으로 보내지 마세요).
      · '조회' 화면(본문 없는 접수 등록 문서)은 건너뛰고, 보안(암호) 문서는 홈넷 비밀번호로 열어 봅니다.
      · 결재란의 직원 이름(과장·대리 등)은 가리지 않습니다. 사람이 아닌 말이 000으로 바뀌거나
        이름이 남을 수 있으니, 밖으로 보내기 전에 PDF를 한 번 훑어봐 주세요.
  - [🔗 관련 문서] (공문 작성 화면 입력칸 아래)
      관련 문서 제목 일부를 적으면(여러 개는 쉼표) 자동 작성 때 홈넷 [문서링크]로 그 문서를 본문에 넣습니다.
      · 서식에 {관련문서} 자리가 있으면 그 자리에, 없으면 1안 본문 맨 위에 '관련: …' 줄로 넣습니다.
      · 문서링크 창에서 제목으로 찾아 맨 위(최신) 문서를 고릅니다. 못 찾으면 '[문서링크: 검색어]' 글자가
        남고 진행 상황에 직접 넣는 방법을 알려 줍니다.
  - 이 PC 안에만 저장합니다(어디로도 보내지 않음). 비밀번호는 기록에 남기지 않습니다.

■ v1.3 바뀐 점 (새 디자인)
  - 화면을 새로 꾸몄습니다: 왼쪽 메뉴 + 옅은 파랑 바탕 + 흰 카드.
      왼쪽 메뉴 : 홈 · 공문 작성 · 서식 고르기 · 작성 이력 · 환경 설정,
                  아래 카드에 관리소·단지명·담당자 (누르면 환경 설정)
  - 처음 화면(홈)
      · 인사말과 검색칸 : 공문 이름 일부를 적으면 모든 분야의 서식을 찾아 아래로 펼칩니다(Enter = 첫 결과).
      · 파란 배너의 [새 공문 작성하기] : 지금 분야의 서식 고르기로 갑니다.
      · 분야 카드 4개(임대·시설·주거복지·주택관리) : 누르면 그 분야 서식 고르기.
      · 통계 : 작성한 문서 · 등록된 서식 · 이번 달 작성 (작성 이력 기준)
      · 바로가기 : 단지기본정보 · 서식 폴더 열기 · 대장 문서 받기 · 사용 방법
      · 최근 작성 문서 : 최근에 홈넷에 작성한 공문 (전체보기 = 작성 이력)
  - 새 공문 작성 화면 (홈의 [새 공문 작성하기] · 왼쪽 메뉴 [서식 고르기])
      · 분야 탭 [임대] [시설] [주거복지] [주택관리] 을 누르면 그 분야 서식을 매월·기타·매주 묶음으로 보여 줍니다.
      · 오른쪽 검색칸 '비슷한 공문 찾기' : 모든 분야에서 비슷한 공문을 찾아 비슷한 순서로 보여 줍니다.
          - 이름·제목이 맞는 서식이 먼저, 분류·본문 내용이 비슷한 서식이 뒤에 나옵니다.
          - 띄어쓰기가 달라도 찾습니다(예: '승강기점검' → 승강기 자체점검 보고).
          - 각 결과에 분야, 맞은 곳(제목 일치·분류 일치·내용 일치·이름 비슷), 본문 한 줄 미리보기가 보입니다.
          - 결과를 누르거나 Enter(첫 결과)로 바로 작성합니다. Esc는 검색어 지우기.
      · 홈 검색칸 아래 [비슷한 공문 모두 보기]를 누르면 이 화면에서 전체 결과를 봅니다.
  - 작성 이력 화면 : logs\작성이력_년월.csv 전체를 최근 것부터 보여 줍니다(실패는 빨간색).
  - 서식 고르기 · 기본정보 화면도 같은 카드 모양으로 바꿨습니다. 공문 작성 기능은 그대로입니다.

■ v1.2 바뀐 점
  - 처음 화면 사진을 본사 사진으로 바꿨습니다.
  - 처음 화면 검색칸 : 공문 이름 일부(예: 승강기, 관리비, 갱신)를 적으면 모든 분야의 서식을 찾아 줍니다.
    결과를 누르거나 Enter(첫 번째 결과)를 누르면 그 공문으로 바로 갑니다. Esc는 검색어 지우기.
  - 창 모드 : 화면의 80% 안쪽 크기 창으로 열리고, 창 크기·위치는 닫을 때 기억합니다.
    [F11] 또는 [파일 → 창 최대화 / 원래 크기]로 최대화했다 되돌릴 수 있습니다.
  - 화면 배율(150% 등)에서 처음 화면 글자가 겹치던 것을 고쳤습니다.

■ v1.1 통합판 (임대 공문작성기 + 자동공문작성기 ai3 관리업무 서식)
  - 임대 서식 25종과 화면은 그대로입니다.
  - 관리업무(월별·주별) 서식 64종을 시작 화면 분야에 나눠 넣었습니다.
      임대     : 기존 임대 서식 + 임대·계약 월별 4종(임대차 계약 갱신 안내 등)
      시설     : 당직·승강기·안전점검·환경정비 등 12종
      주거복지 : 마이홈·간담회·클린데이·돌봄 등 19종
      주택관리 : 관리비·회계, 교육·행사, 보고·공개 26종 + 매주 작성 3종
    서식 고르기 화면에서 '매월 작성하는 공문' / '매주 작성하는 공문' / '기타 공문'으로 나뉩니다.
  - [파일 → 단지기본정보] : 관리소명·평형·세대수·계좌·업체를 한 번 넣어 두면
    월별·주별 서식의 {단지:…} 칸에 자동으로 들어갑니다. (처음 값은 광주우산3 기준)
  - 숫자·금액 칸은 표의 금액·합계가 자동으로 계산됩니다(예: 저장품 구입, 관리비예치금 청구).
  - 관리비예치금 청구는 작성을 마치면 이번 달 누적액이 다음 달 '전월누적' 처음 값으로 저장됩니다.
  - ai3의 '표 행·열 추가/삭제 단추'는 넣지 않았습니다. 표 모양은 [✏ 본문 직접 고치기]로 고칩니다.
  - 참고 자료: 공문양식_PDF(원본 양식), tools(한글 HML → 서식 변환 도구)

■ 처음 한 번
  1. 공문작성기.exe를 더블클릭합니다. (설치 필요 없음)
  2. [① 계정·기본정보] 탭에 입력하고 [저장하고 다음]을 누릅니다.
     - 홈넷 아이디(사번)·비밀번호
     - VPN 아이디·비밀번호 : 사무실 밖에서 쓸 때만. 사무실(사내망)에서는 비워도 됩니다.
     - 관리소명·단지명·담당자·전화번호 : 공문의 빈칸에 자동으로 들어갑니다.

■ 공문 쓸 때마다
  1. 왼쪽 메뉴 [서식 고르기](또는 처음 화면 검색칸)에서 서식을 고릅니다.
  2. 받는 분 이름과 날짜를 넣습니다. 빨간 * 표시는 꼭 넣어야 하는 칸입니다.
     날짜 칸의 ▼를 누르면 달력이 나옵니다.
     - 여러 명에게 보낼 때는 [📎 업로드할 엑셀 고르기]로 홈넷 수신자 엑셀을 고르세요.
       자동 작성 때 결재정보 → 설정 → 수신자 → 수기입력 → [업로드]로 대신 올려 줍니다.
       엑셀로 보내면 받는 분 이름·동호 칸은 넣지 않습니다. 안 쓰려면 [빼기].
     - 차수가 있는 서식은 차수를 숫자로 적고 Enter를 누르면 홈넷에서 그 차수의 결과 통보 문서를 찾아
       관련 문서 링크와 날짜를 자동으로 넣습니다.
     - [🔗 관련 문서번호]에 문서번호를 적으면 그 문서를 [문서링크]로 본문에 넣습니다.
     - [✔ 올바른 문서 만들기]로 날짜·금액·항목 번호·끝 표시 등을 공문서 규칙대로 고칠 수 있습니다.
     - 05번(영구임대)·06번(국민임대) 갱신계약 사전서류 제출 안내는 1안 내부결재와 2안 입주자 안내를
       한 번에 작성합니다. 수신자(엑셀 업로드)는 2안에만 들어갑니다.
       [1안 내부결재 함께 작성]을 끄면 입주자 안내만 작성합니다.
  3. 아래 '확인하기'에서 제목·수신자와 빈칸 안내를 봅니다.
     - 본문은 [✏ 본문 직접 고치기]를 누르면 열립니다. 빨간 표시는 아직 채우지 않은 칸입니다.
     - [브라우저로 미리보기] : 표까지 실제 모양으로 볼 수 있습니다.
  4. [홈넷에 자동 작성]을 누르면 브라우저가 열리고 자동으로 작성합니다.
  5. 브라우저에서 내용을 확인하고, 붙임 파일이 있으면 첨부한 뒤 [결재올림]을 직접 누릅니다.

  ※ 작성이 끝날 때까지 브라우저 창을 닫지 마세요.
  ※ 처음 실행할 때는 브라우저 준비에 30초쯤 걸릴 수 있습니다.

■ 서식 고치기·추가하기
  - 메뉴 [파일 → 서식 폴더 열기]의 txt 파일을 메모장으로 고치거나 복사해 새로 만듭니다.
  - 프로그램 안에서 [✏ 본문 직접 고치기] → [고친 내용을 서식에 저장]으로도 고칠 수 있습니다.
  - 빈칸 규칙은 메뉴 [도움말 → 서식 만드는 법]을 보세요.

■ 문제가 생기면
  - 진행 기록 : 프로그램 폴더의 logs\app_날짜.log
  - 작성 이력 : logs\작성이력_년월.csv
  - 담당자가 바뀌면 [파일 → 저장된 계정 지우기]
