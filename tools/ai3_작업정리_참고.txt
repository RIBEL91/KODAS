--------------------------------------------------------------------
1단계. ai2 기반 새 앱 만들기 + 단지기본정보 탭 + 서식 정리
--------------------------------------------------------------------
■ 탭 구성
  ① 계정·기본정보  →  ② 단지기본정보 (새로 추가)  →  공문작성

■ ② 단지기본정보 탭 (새 파일 app\complex_info.py)
  - 기본 : 관리소명, 단지명, 단지약칭, 공급유형, 난방방식, 총세대수, 동범위,
           주거행복지원센터, 주거복지상담실, 관할구청
  - 계좌·업체 : 계좌번호, 사업자등록번호, 경비/청소/승강기 업체, 회보제작업체
  - 평형1~6 과 평형별 세대수 (처음 값 : 광주우산3 — 39.85㎡ 588세대, 39.87㎡ 149세대,
    43.92㎡ 239세대, 45.26㎡ 298세대)
  - 자동 계산 : 평형수, 평형목록, 평형별세대 / 총세대수를 비우면 평형별 세대수 합계
  - [직접 추가하는 항목]에 '이름=값'으로 항목을 더 넣을 수 있음
  - 서식에서는 {단지:관리소명}, {단지:평형1}, {단지:평형1세대수} 처럼 씀
  - 공문작성 화면에서 단지기본정보에서 들어간 값은 보라색으로 표시, 누르면 해당 칸으로 이동

■ 서식 정리 (69개 → 64개)
  - 내용이 같은 중복 서식 5종 삭제
      관리비정산('년 부과)              → 관리비정산 보고('년 부과)만 남김
      당직명령 편성                     → 당직명령 편성 보고만 남김
      사이버 보안진단의 날 실시 보고     → 사이버 보안진단의 날 실시(최신 관련문서)만 남김
      재활용폐기물 배출실적 보고(월)     → 재활용폐기물 배출실적 신고(월)만 남김
      고지 관리비 … 홈페이지 공개        → 고지 관리비 … 홈페이지 공개 보고만 남김
    (비슷해 보이지만 내용이 다른 '동별 게시판 공개', 주별 서식 등은 둘 다 유지)
  - 공문양식 PDF와 대조해 표가 깨져 있던 서식 15종 다시 작성
      민원 처리현황, 고지 관리비 공개 2종, 저장품 구입, 안전점검의 날 3종,
      승강기 자체점검, 외상매입금, 소모품비 2종, 나누리, 폭염 물품, 갱신계약 촉구,
      관리비예치금 청구(평형1~4 기준 자동 계산)
  - 관리소명 등이 박혀 있던 26종을 {단지:…} 자동 입력으로 바꿈
    (예: "광주우산3관리소-" → "{단지:관리소명}-")

■ 함께 고친 오류
  - 표 칸 안의 날짜 입력칸({날짜:x|공문})의 '|' 때문에 표가 깨지던 문제
  - 계산식에서 빈 칸이 있으면 오류가 나던 문제 (빈 칸은 0으로 계산)

--------------------------------------------------------------------
2단계. 표 고치기 — 오른쪽 클릭 메뉴 방식 (3단계에서 없앰)
--------------------------------------------------------------------
  - 오른쪽 클릭 메뉴(행/열 넣기·지우기, 칸 합치기/나누기, 머리글, 표 지우기)와
    [▦ 표 넣기] 버튼을 만들었으나, 요청에 따라 3단계 방식으로 바꾸며 모두 삭제

--------------------------------------------------------------------
3단계. 표 고치기 — 공문 속 원래 표를 행·열 단추로 고치고, 넣을 값도 함께 바뀌게
--------------------------------------------------------------------
■ 사용 방법
  - [3. 확인하기]의 표마다 바로 아래에 [＋행] [－행] [＋열] [－열] 단추
  - 표 칸을 먼저 누르면 그 행 아래·그 열 오른쪽에 추가 / 그 행·열을 삭제
    (아무 칸도 안 눌렀으면 마지막 행·마지막 열 기준)

■ 넣을 값이 함께 바뀜
  - ＋행 : 위 행을 본떠 새 행 생성, 새 칸이 '2. 필요한 내용 넣기'에 입력칸으로 생김
           예) 저장품 구입 → 구입처②·품명②·단위②·수량②·단가②·비고②
               새 행 금액 자동 계산, 합계 행에 자동으로 더해짐
           예) 관리비예치금 청구 → 평형5 행, 공가세대수(평형5)·전월누적(평형5),
               다음 달로 넘기는 누적값 설정까지 함께 생김
  - －행 : 그 행의 넣을 값 칸·입력값이 함께 없어지고 합계에서도 빠짐
  - ＋열 : 열 이름을 정하면 내용 행마다 '열이름+번호' 입력칸 생성 (예: 확인자1, 확인자2)
  - －열 : 그 열의 넣을 값 칸이 함께 없어짐
  - 공문 안의 값 칸(파란색)을 직접 고치면 넣을 값 칸에도 같은 값이 들어가고 다시 계산
    예) 공문에서 수량 10 → 20 으로 고치면 넣을 값 수량도 20, 금액 10,000
  - [💾 서식으로 저장] 하면 바뀐 표 모양이 다음부터 그대로 유지

■ 막아 둔 경우 (안내창만 뜨고 표는 그대로)
  - 머리글 행 지우기
  - 내용 행이 하나뿐일 때 그 행 지우기
  - 지우려는 칸이 다른 곱하기 계산 등에 쓰이는 경우

■ 알아 둘 점
  - 새 행은 글자만 있던 칸도 빈 입력칸이 됨 (예: "슈퍼데이365" → 빈 '구입처②')
    새 행 값은 직접 넣어야 함
